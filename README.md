# ⚡ HyperShare (هایپرشیر)
### سیستم انتقال فایل فوق‌سریع P2P موبایل (ویژه شرایط پرتابل، خیابان و بدون اینترنت)

هایپرشیر یک جایگزین مدرن، فوق‌سبک و بدون تبلیغات برای برنامه‌های قدیمی و سنگینی مثل **Shareit** و **Zapya** است که برای انتقال فایل بین دو گوشی در خیابان، دانشگاه یا سفر (بدون نیاز به هیچ مودم یا دیتای اینترنت) طراحی شده است.

---

## 🚀 چرا سرعت هایپرشیر فضایی است؟ (مقایسه با شیرایت و زاپیا)

| مشخصه | شیرایت و زاپیا | هایپرشیر (HyperShare) |
| :--- | :--- | :--- |
| **میانگین سرعت انتقال** | ۱۵ تا ۳۰ مگابایت بر ثانیه | **۸۰ تا ۱۵۰+ مگابایت بر ثانیه** |
| **فرکانس امواج** | باند شلوغ 2.4GHz | **باند خلوت و عریض 5GHz (Wi-Fi 5 / Wi-Fi 6)** |
| **نیاز به نصب برنامه در مقصد** | اجباری (گیرنده حتماً باید اپ را داشته باشد) | **اختیاری (Zero-Install)**: گیرنده فقط با دوربین اسکن کرده و از مرورگر دانلود می‌کند |
| **مجوزهای آزاردهنده** | اجبار به روشن کردن GPS و Bluetooth | **بدون نیاز به لوکیشن و بلوتوث** (اتصال تک‌مرحله‌ای با QR Code) |
| **معماری انتقال داده** | تک‌استریم کند TCP | **شتاب‌دهنده ۸ کاناله موازی (Multi-Stream HTTP Range)** |
| **سربار و تبلیغات** | صدها مگابایت بازی، اخبار، تبلیغات و مصرف باتری | **فایل تک و سبک (~۱۰ مگابایت)** با حداقل مصرف رم و پردازنده |

## 📱 سناریوی استفاده در خیابان (کاملاً آفلاین)

1. **گوشی فرستنده (Sender)**:
   - هات‌اسپات ۵ گیگاهرتز را روشن کرده و برنامه را باز می‌کند.
   - بارکد (QR Code) روی صفحه نمایش داده می‌شود.

2. **گوشی گیرنده (Receiver)**:
   - دوربین عکاسی گوشی را باز کرده و بارکد را اسکن می‌کند.
   - گوشی گیرنده فوراً به وای‌فای ۵ گیگاهرتز متصل شده و صفحه دریافت فایل‌ها در مرورگر باز می‌شود.
   - هیچ نیازی به بلوتوث، لوکیشن، اینترنت یا نصب قبلی اپلیکیشن نیست!

3. **انتقال با حداکثر سرعت**:
   - با زدن دکمه «شلیک توربو»، فایل به صورت همزمان روی ۸ کانال موازی دانلود شده و سرعت به سقف فیزیکی کارت شبکه گوشی می‌رسد.

## 💻 نحوه اجرا و تست

### اجرای مستقیم روی سیستم:
```powershell
cd C:\Users\HP\.gemini\antigravity\scratch\hypershare
.\hypershare.exe -port 8080 -dir ./shared
```

### کامپایل برای موبایل اندروید (معماری ARM64):
```powershell
$env:GOOS="android"; $env:GOARCH="arm64"; go build -o hypershare_arm64 main.go
```
این فایل خروجی مستقیماً درون سورس اندروید (از طریق NDK یا به عنوان سرویس پس‌زمینه) یا داخل شل Termux قابل اجراست.
